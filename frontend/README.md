# Frontend - SAHAYAK

React + Vite frontend application for SAHAYAK.

## Scope of Development
- **User Interface**: Citizen portal, Officer grievance handling dashboard, and Administrator management panel.
- **Voice First Interaction**: Voice recording, speech input components, language selection, and live transcript visualization.
- **Scheme Discovery & Eligibility**: Scheme search, category filters, eligibility questionnaires, and explainable result cards.
- **Grievance Redressal**: Ticket submission forms, status tracking timelines, and officer resolution workflows.
- **State & Services**: API service layer, authentication context, and multilingual UI support.
