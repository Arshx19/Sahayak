# Database - SAHAYAK

MongoDB database configurations, schemas, and seed datasets for SAHAYAK.

## Scope of Development
- **Document Schemas**: JSON schemas defining data structures for collections (`users`, `citizen_profiles`, `schemes`, `scheme_rules`, `eligibility_checks`, `conversations`, `grievances`, `grievance_updates`, `audit_logs`).
- **Indexes**: Query optimization indexes, compound indexes, and uniqueness constraints.
- **Seed Data**: Sample government schemes, eligibility rule definitions, and initial administrative user profiles.
- **Migrations & Scripts**: Database initialization scripts and snapshot utilities.
