# AI & Intelligence - SAHAYAK

AI pipelines, voice translation services, and deterministic rules engine for SAHAYAK.

## Scope of Development
- **BHASHINI Integration**: Speech-to-Text (STT), multilingual translation across Indian languages, and Text-to-Speech (TTS).
- **LLM Pipeline**: Conversational understanding, citizen profile parameter extraction from unstructured voice text, and prompt management ("LLM Understands").
- **Deterministic Rules Engine**: Python-based rules engine evaluating profile attributes against scheme criteria to generate explainable eligibility outcomes ("Rules Decide").
- **Grievance Intelligence**: Intent classification, scheme identification, priority scoring, and department routing.
